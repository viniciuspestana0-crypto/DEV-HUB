JavaScript

Introdução

Uma linguagem de programação feita para ser uma linguagem de script para web. Sua versão inicial foi feita apressadamente, com sintaxe baseada em C, tipagem dinâmica, com um dos seus pontos mais fortes sendo a fácil serialização de dados para comunicação via rede (usado massivamente para comunicação entre sites e servidores).
Um ponto negativo da linguagem é sua tipagem dinâmica aliadas a conversões automáticas de tipo, que podem ser motivo de problemas no desenvolvimento, a linguagem Typescript foi criada como uma solução para isso, mas hoje em dia também podemos utilizar JSDoc.
A linguagem Javascript que foi inicialmente uma solução simples feita somente para Web, teve seu ambiente expandido massivamente ao longo dos anos, possibilitando a criação de programas desktop, mobile, de terminal, servidores, automações, etc.

Documentação

Mozilla: Documentação do Javascript disponível no site da Mozilla, bastante completa e disponível em português e inglês, também tem as documentações sobre APIs do navegador, HTML e CSS.
Google: Documentação de algumas funcionalidades do navegador, não é tão completo como o `Mozilla` mas tem alguns posts bem interessantes e documentações sobre o sistema de extensões do chrome.
ECMAScript: Padronização da `Ecma International` que deve ser seguida por linguagens de scripts utilizadas para web, Javascript na verdade é uma das linguagens que segue o padrão definido pela `Ecma`, portanto o Javascript segue todas essas especificações.

Guias
